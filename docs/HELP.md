# LSO (Local System Optimizer) — Help Guide

## What is LSO?

LSO is a privacy-first desktop app that helps you keep your computer clean, fast, and secure. It runs entirely offline — no data ever leaves your machine.

---

## Getting Started

### Launch the App

```bash
cargo tauri dev
```

When the app opens, you'll see the **Dashboard** — your system health overview.

### First Scan

Click **"Scan Now"** on the dashboard. LSO will analyze your system and display:
- Disk usage per volume
- Memory usage
- CPU load
- Running processes
- Cleanup recommendations

---

## Features

### 1. Disk Usage Monitor

Shows how much space each drive/partition is using. Highlights volumes running low on space.

**Where to find it:** Dashboard → Disk Usage card

---

### 2. Memory & CPU Monitor

Displays current RAM usage and CPU load. Helps you spot resource-hungry processes.

**Where to find it:** Dashboard → Memory card, CPU card

---

### 3. Process Viewer

Lists running processes with resource consumption. Useful for finding apps that are slowing your system down.

**Where to find it:** Dashboard → Process table

---

### 4. Smart Recommendations

LSO uses a rule engine to generate actionable recommendations based on your system state. For example:
- "Temp files are using 2.3 GB — clean up?"
- "Disk is 92% full — review large files"
- "3 startup items are slowing boot time"

**Where to find it:** Dashboard → Recommendations section

**How it works:** Recommendations are generated by deterministic rules (not AI guesses). Each recommendation shows what it will do, the expected space savings, and its risk level.

---

### 5. Temp File Cleanup

Safely removes temporary and cache files to free disk space.

**What it cleans:**
- System temp folders (`/tmp`, `%TEMP%`)
- User cache directories (`~/Library/Caches`, `~/.cache`)
- Application logs older than 30 days

**Safety guarantees:**
- Never deletes files modified in the last 24 hours
- Never deletes files currently open by another program
- Shows you exactly what will be deleted and how much space you'll recover
- Creates a snapshot before any deletion so you can undo

**How to use:**
1. Review the cleanup recommendation on the dashboard
2. Click to see details (files, sizes)
3. Approve the cleanup in the confirmation dialog
4. Done — space recovered

---

### 6. Startup Item Manager

Finds programs that launch at login/boot and lets you disable unnecessary ones to speed up startup time.

**What it detects:**
- macOS: Launch Agents, Login Items
- Linux: systemd services, autostart entries
- Windows: Registry Run keys, Task Scheduler, Services

**How to use:**
1. LSO scans for startup items automatically
2. Items flagged as unnecessary appear in recommendations
3. Review the item details (name, publisher, command)
4. Approve to disable — original state is snapshotted for rollback

---

### 7. File Classification & Organization

AI-powered file analysis that categorizes your files and suggests how to organize them better.

**Categories detected:** Documents, Media, Code, Archives, Data, Temporary

**What it finds:**
- Duplicate files (exact and near-duplicate)
- Large unused files
- Scattered project files that could be grouped

**Requires:** Ollama running locally (optional feature — app works without it)

---

### 8. Security Posture Scanner

Checks your system for common security misconfigurations.

**What it checks:**
- Open network ports (and which process owns them)
- File/folder permissions that are too open
- Firewall status (enabled/disabled, default policy)
- World-writable files in sensitive locations

**Where to find it:** Scans run automatically; issues appear as recommendations

---

### 9. AI-Powered Explanations

When Ollama is running locally, LSO can explain recommendations in plain language — why something matters, what the risk is, and what the fix does.

**Setup:**
1. Install [Ollama](https://ollama.ai)
2. Pull a model: `ollama pull llama3`
3. Keep Ollama running — LSO connects on `localhost:11434`

**Note:** AI is optional. All decisions are made by the rule engine, not the AI. The AI only provides explanations.

---

### 10. Audit Log

Every action LSO takes is logged. You can review what was done, when, and undo if needed.

**Where to find it:** Audit Log view in the app

**What's logged:**
- What action was performed
- When it happened
- What was affected (files, services, etc.)
- Outcome (success/failure)
- Snapshot reference for rollback

## Safety & Privacy

| Guarantee | Details |
|-----------|---------|
| **No network access** | LSO never connects to the internet. Zero telemetry. |
| **Snapshot before action** | Every change creates a rollback point first. |
| **Approval required** | Nothing is deleted or changed without your explicit OK. |
| **Read-only scanning** | System scans never modify anything. |
| **Local AI only** | If AI is used, it runs on your machine via Ollama. |

## Troubleshooting

### App won't start
```bash
cargo build --workspace   # Check for build errors
cargo tauri dev           # Run with logs visible
```

### Scan shows no data
- Make sure you clicked "Scan Now"
- Check the terminal for error messages

### AI explanations not showing
- Verify Ollama is running: `curl http://localhost:11434/api/tags`
- Pull a model if needed: `ollama pull llama3`
- AI features are optional — the app works without them

### Cleanup didn't free expected space
- Some files may have been recreated by running programs
- Check the audit log to confirm what was actually deleted
- Trash/Recycle Bin items require separate approval

# Frontend

# Run
cargo tauri dev
